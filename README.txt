HOW TO USE
1. Open index.html in your browser (double-click it). No installation needed.
2. Edit index.html with any text editor (VS Code is good) and replace the placeholder text.
3. Put your photo in images/, your resume as resume.pdf, and certificates in a certificates/ folder.
4. Change colours at the top of style.css.
5. To publish for free: upload the folder to GitHub, then turn on GitHub Pages (Settings > Pages),
   or drag the folder onto netlify.com/drop.
